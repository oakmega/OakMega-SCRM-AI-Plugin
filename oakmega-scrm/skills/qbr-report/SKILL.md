# QBR Report

產出一份涵蓋帳號總覽、好友成長、發布文章成效三大區塊的分析報告。可依需求輸出純文字、PPT、網頁三種格式之一或多種，三種格式共用同一套分析結果，不會各自重新計算。

## 前置依賴

資料透過 `oakmega-scrm` 專案的 `data-fetcher` skill 呼叫 CLI 取得，執行本 skill 前需確認 `data-fetcher` 可用（API key 已設定）。

## 流程

### 第一步：確認報告範圍與格式

務必先用 AskUserQuestion 詢問使用者，就算對話有說明，也還是要重複確認：

1. 時間單位（週／月／雙月／季）與本期起訖日期
2. 要輸出哪些格式：純文字（.md）／網頁（.html）／PPT，可複選

未取得回覆前不要往下執行。

### 第二步：撈取資料並分析

依 `reference/analyze.md` 執行：

1. 讀「資料撈取一覽」段落，依序呼叫對應 CLI（透過 `data-fetcher` skill）
2. 依帳號總覽分析／好友成長分析／發布文章成效各段落的定義，算出這次需要的所有數字、標記、與數據小結（數據小結撰寫依 `reference/analyze.md` 的「數據小結撰寫原則」，以 CRM 專家角度提出分析，不只是複述數據）
3. 這一步只做一次：不論使用者選了幾種格式，都共用這次算出的結果，不重新計算

### 第三步：依格式生成

依第一步使用者選擇的格式，參照對應範例的排版風格直接生成內容，不產出中繼資料檔案。

- 純文字：參考 `example/example.md`
- 網頁（html）：參考 `example/example.html`

若選了多種格式，依序產出；因為都來自同一次分析結果，內容必須彼此一致（數字、數據小結用詞可依格式調整語氣，但結論不能互相矛盾）。

### 第四步：交付

完成後把產出的檔案提供給使用者。

## 注意事項

- 指標公式、排除規則、insight 判斷原則一律以 `reference/analyze.md` 為準，不在這裡重複或另外定義。
